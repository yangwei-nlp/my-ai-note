# 这篇论文主要讨论什么问题？

经典的残差连接如下：（残差连接配合Pre-Norm是现代LLM的标准架构了）

$h_l=h_{l-1}+f_{l-1}(h_{l-1})$，可以发现每层的输入是词嵌入和先前层输出的固定权重求和（因为每层对后面权重系数都是1）。

这种设计虽然通过恒等映射提供了梯度高速公路，使深层训练成为可能，但在深度维度上存在与早期序列建模类似的瓶颈：

**在序列维度上，Transformer 已通过注意力机制取代了 RNN 的固定递推；但在深度维度上，信息聚合仍使用"固定权重累加"这一类似 RNN 的压缩方式。**

具体来讲，传统的Pre-Norm的问题如下：

| 问题            | 一句话总结                                   | LLM 例子                                                  |
| ------------- | --------------------------------------- | ------------------------------------------------------- |
| **信息稀释**      | 早期层提取的关键特征被后续无数层均匀累加"平均掉"，深层难以精准调用浅层信息。 | 用户输入"**这部电影不好看**"，浅层已识别"不"的否定语义，但深层因早期信号被淹没，最终输出正面评价。   |
| **状态膨胀**      | 隐藏状态数值随深度线性增长，压缩有效精度，导致深层计算不稳定。         | 模型续写**10万字长篇小说**时，写到后半段突然输出乱码或重复字符，因为深层激活值过大溢出。         |
| **无选择性访问**    | 每层只能看到压缩后的"混合态"，无法像查档案一样精准回溯某一层原始输出。    | 用户要求"**引用第三段的增长率3.5%**"，深层因无法选择性调取第三层的精确表示，只能模糊回答"约3%"。 |
| **梯度不均与深度低效** | 反向传播时浅层梯度过大、深层过小，导致堆叠更多层收益递减。           | 把7B模型扩展到70B后，**数学推理题准确率提升微弱**，因为新增深层参数更新不足，"白堆了层数"。     |


论文的核心论点正是：既然 Transformer 在序列维度上通过注意力解决了 RNN 的信息瓶颈，深度维度上也应该做同样的事。 AttnRes 的实验结果（下游任务全面提升、训练动态更健康、Scaling Law 更高效）证明了这种"深度 RNN 式压缩"确实是一个值得修复的严重问题。
