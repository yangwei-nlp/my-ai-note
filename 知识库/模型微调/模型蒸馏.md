# 模型蒸馏 (Model Distillation)

## 简介

模型蒸馏是一种知识迁移技术，将大模型（教师模型）的知识迁移到小模型（学生模型），使学生模型在保持较小体积的同时获得接近教师模型的性能。在微调领域，蒸馏常与指令微调结合使用。

## 核心思想

```
教师模型（大）          学生模型（小）
   ↓                        ↓
生成软标签  ──────────→   模仿学习
生成推理过程 ──────────→   思维链学习
```

### 为什么有效？

- **软标签**：教师模型的概率分布包含类别间关系信息
- **暗知识**：错误类别的相对概率蕴含知识
- **推理过程**：教师的中间推理步骤提供学习材料

## 蒸馏类型

### 1. 知识蒸馏 (Knowledge Distillation, KD)

**经典方法（Hinton, 2015）**

```
硬标签: [0, 0, 1, 0]            → "这是猫"
软标签: [0.01, 0.02, 0.85, 0.12] → "87%是猫，10%可能是狗"
```

**损失函数**：

```python
def distillation_loss(student_logits, teacher_logits, labels, T=4.0, alpha=0.5):
    # 软目标损失（KL散度，使用温度T）
    soft_loss = F.kl_div(
        F.log_softmax(student_logits / T, dim=1),
        F.softmax(teacher_logits / T, dim=1),
        reduction='batchmean'
    ) * (T * T)
    
    # 硬目标损失（交叉熵）
    hard_loss = F.cross_entropy(student_logits, labels)
    
    # 加权组合
    return alpha * soft_loss + (1 - alpha) * hard_loss
```

### 2. 指令跟随蒸馏

**方法**：使用教师模型生成指令-回答对，再用这些数据训练学生模型

```
Self-Instruct Distillation:
1. 种子指令 → 教师生成新指令
2. 新指令 → 教师生成高质量回答
3. 用生成的数据训练学生模型
```

### 3. 思维链蒸馏 (Chain-of-Thought Distillation)

**目标**：让学生模型学会教师的推理过程

```python
# 教师生成思维链
teacher_output = teacher_model.generate(
    "问题：23+47=？\\n请逐步思考：",
    max_length=100
)
# 输出："首先个位相加：3+7=10，进1..."

# 学生学习完整推理链
training_data.append({
    "instruction": "23+47=？",
    "output": teacher_output  # 包含推理过程
})
```

## 大模型蒸馏实践

### 1. 通用蒸馏流程

```python
def distill_model(teacher, student, train_data, epochs=3):
    optimizer = AdamW(student.parameters(), lr=5e-5)
    
    for epoch in range(epochs):
        for batch in train_data:
            # 教师生成输出
            with torch.no_grad():
                teacher_logits = teacher(**batch).logits
            
            # 学生前向传播
            student_logits = student(**batch).logits
            
            # 计算蒸馏损失
            loss = distillation_loss(
                student_logits, 
                teacher_logits, 
                batch['labels']
            )
            
            # 反向传播
            loss.backward()
            optimizer.step()
            optimizer.zero_grad()
```

### 2. 数据增强蒸馏

使用教师模型生成多样化的训练数据：

```python
# 生成多样化的回答
def generate_augmented_data(teacher, prompts, num_samples=5):
    augmented_data = []
    for prompt in prompts:
        for _ in range(num_samples):
            # 使用不同温度采样
            temperature = random.uniform(0.5, 1.5)
            output = teacher.generate(
                prompt,
                temperature=temperature,
                do_sample=True
            )
            augmented_data.append({
                "instruction": prompt,
                "output": output
            })
    return augmented_data
```

## 与微调的关系

```
微调 vs 蒸馏

微调：更新模型参数以适应特定任务
      ↓
   提升任务性能

蒸馏：学习另一个模型的行为
      ↓
   压缩模型 + 性能保持

结合：蒸馏后的模型可以进一步微调
```

## 实践建议

1. **选择合适的教师**：性能越好、越大，蒸馏效果通常越好
2. **温度调节**：T=2-4 通常效果较好
3. **α 参数**：软标签权重 0.5-0.7 较优
4. **数据多样性**：覆盖多种任务和难度
5. **迭代优化**：学生可作为新教师继续蒸馏
