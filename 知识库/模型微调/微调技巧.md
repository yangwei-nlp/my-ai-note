# 微调技巧 (Fine-tuning Tips)

## 1. 数据层面

### 数据质量 > 数据数量
- 少而精的数据往往比大量低质数据更有效
- 推荐使用 1K-10K 高质量样本精调

### 弱点分析驱动的数据构造
- 在测试集上分析模型错误类型
- 针对薄弱场景定向构造训练数据
- 迭代优化：测试 → 分析 → 构造数据 → 重新训练

### 数据多样性
- 覆盖任务的各种变体和边界情况
- 包含不同难度级别的问题
- 避免数据重复导致的过拟合

## 2. 训练策略

### 学习率调度
```
推荐配置：
- 初始学习率：1e-5 ~ 5e-5
- Warmup：3% 的步数
- 调度器：Cosine with Restarts 或 Linear
```

### 训练轮数
```
- SFT：1-3 个 epoch（过多会过拟合）
- DPO：1-2 个 epoch
- PPO：动态收敛判定
```

### 混合训练
- 指令微调与原始能力保持的平衡
- 建议保留 10-20% 通用能力数据

## 3. 过拟合防范

| 策略 | 说明 |
|------|------|
| **Early Stopping** | 验证集性能不再提升时停止 |
| **Weight Decay** | 0.01-0.1 的权重衰减 |
| **Dropout** | 在全连接层添加 dropout |
| **数据增强** | 同义改写、模板变化 |

## 4. 显存优化

### 梯度累积
```python
# 小 batch size 模拟大 batch
training_args = TrainingArguments(
    per_device_train_batch_size=1,
    gradient_accumulation_steps=8,  # 等效 batch size = 8
)
```

### 混合精度训练
```python
# FP16 或 BF16
training_args = TrainingArguments(
    fp16=True,     # 或使用 bf16=True
)
```

### 梯度检查点
```python
# 时间换空间
model.gradient_checkpointing_enable()
```

## 5. 评估与调优

### 持续监控指标
- 训练 loss：是否稳定下降
- 验证 loss：检测过拟合
- 生成样例质量：人工抽查

### 早停策略
```python
from transformers import EarlyStoppingCallback

trainer = Trainer(
    ...,
    callbacks=[EarlyStoppingCallback(early_stopping_patience=3)]
)
```

## 6. 多轮对话特殊处理

### 长度采样
- 按长度分组，避免 padding 浪费
- 或使用动态 batching

### 角色区分
```
<User>: 用户输入
<Assistant>: 模型回复
<System>: 系统提示
```

## 7. 灾难性遗忘缓解

| 方法 | 说明 |
|------|------|
| **Replay** | 保留部分原始能力数据混合训练 |
| **EWC** | 弹性权重巩固，保护重要参数 |
| **LoRA** | 低秩适配，减少可训练参数 |
| **Adapter** | 只训练新增的适配器层 |

## 8. 部署优化

### 模型合并
```python
# LoRA 权重合并到基模型
model = model.merge_and_unload()
```

### 量化导出
```python
# 导出为 GPTQ/AWQ 格式
model.save_pretrained("./merged_model")
```
